# V5.2 — isolated DEV effect appearance

Not imported by the product or TEST immutable runtime. Human review pending.

- Base is the unchanged V4 raster, overlays and approved V5.6 material.
- RGB-only material subclass: one dorsal edge lane, sparse glints; corruption is localized muted cracks. No global hue replacement. Face/cap overlays are never tinted; moss pixels are exempt.
- Composition: localized negative cracks → short Guard shell → one dominant edge (Rush / Focus / Portal / Harvest) → interaction sprites. No full-strength pattern stacking.
- Guard: an independently composited, short translucent cosmetic shell sampled from the same leading path/radius; not a generic circle, collision shape or status icon. Break expands/fades and opens local crack gaps.
- Rush wake is a low-opacity copy of the current V4 mask, continuous rather than tick-anchored sprite objects.
- Spores interaction uses only 3 small existing authored PNG motes, for 30 ticks following the interaction button. No constant orbiting status objects.
- Roots and Mist retain the BASE snake. Their environmental lifecycle is unchanged in TEST, not duplicated in this material fixture.
- The proof timer advances integer ticks. Paused render bytes remain identical. Transitions use the existing deterministic 15-tick (250 ms) tracks.
- Native raster gate compares base/active primary ribbon alpha byte-for-byte, and reports unchanged RGB coverage. Cosmetic external VFX is deliberately separate from that primary geometry metric.

This is an appearance candidate, not final premium VFX production art. The short Guard shell and interaction/break timing require human review. TEST keeps its existing effects until approval. No simulation, portal history, collision, gameplay or backend edits.
