# Production icon prompts

Built-in ImageGen; each image independently generated from scratch, no sheet and no reference pixels used. Twelve RGBA originals were proportionally downsampled to 192×192 PNG, preserving alpha (no cropping or background removal).

## Common final prompt

Create ONE independent production UI icon for Mushroom Fly fantasy game. Subject: [SUBJECT]. Style: premium painted casual fantasy game icon, solid sculpted volume, warm gold and cream, soft bevel, subtle amber/brown depth, lighting from upper left. Simple broad silhouette clearly readable at 20–24 CSS pixels. Front-facing square composition, consistent 12% safe padding. Genuine transparent alpha background. No button tile or frame, no scenery, no text, no checkerboard painted into the image, no halo. A SINGLE icon only, never a sheet or multiple alternatives. Generate from scratch.

- how-to-play: HOW TO PLAY: a small open cream parchment book with golden binding and a simple brown mushroom silhouette on the pages
- continue: CONTINUE: one solid right-facing amber-gold triangular play token with cream bevel, small deep-green inlaid centre
- restart: RESTART: one thick solid golden circular returning arrow, easily understood at tiny size
- home: HOME: simple cream mushroom-house silhouette with red roof, golden doorway, absolutely minimal details
- close: CLOSE: one bold solid golden X, rounded bevelled arms, clear cream highlights
- confirm: CONFIRM: one thick solid golden checkmark with cream bevel highlights
